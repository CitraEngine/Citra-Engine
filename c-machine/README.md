# C-Machine

The C-Machine is a specialized virtual machine for Citra Engine based on the concept behind the z-machine from the Infocom versions of Zork. The C-Machine follows the Ilama ISA, which itself is tightly bound to the workings for Citra Engine and the C-Machine.
<br/>
Detailed documentation for the Ilama ISA is in [Ilama ISA](c-machine/ilama-isa/IlamaIsa.md)
